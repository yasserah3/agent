Road Texture Agent 2026.10.12-saudi-fit3
Focused patch for 2026.10.12-marking-logic2

INSTALL
1. Stop the running Python server.
2. Back up the matching code files before replacing them.
3. Extract this ZIP into the road-texture-agent folder containing server.py.
   Keep the app/ and ui/ folders in the ZIP; merge them with those folders.
4. Restart the server and refresh the browser with Ctrl+F5.
5. Check the console version: 2026.10.12-saudi-fit3.
6. For an existing texture still loaded in the page, press Update 2D texture,
   then Update view in 3D. After a full page refresh, reload the alpha and
   generate once if that page no longer holds the previous generation.

USE
- Road markings: select Saudi Arabia - SHC 602, choose design speed and
  posted/approach speed, then Saudi speed-based dimensions.
- Old saved settings are retained. If an old setting still says As set below
  or Learned, change it to Saudi speed-based dimensions to use the new tables.
- Both highway groups use white centre paint in Saudi mode. Custom / previous
  guide retains the original group 2 yellow centre style and previous settings.
- Decals: Fit all decals to roads enables road-relative fitting on every layer.
  Turn relative fit off disables it. Each layer also has its own fit checkbox.
- Imported artwork scales uniformly from its configured width on a 6 m road,
  capped to fit inside the kerbs. Relative fit aligns it with the road and
  overrides random turning while enabled.
- Arrows and STOP words fit the incoming lane. Stop/give-way/cycle lines fit
  the approach. Yellow box shape follows the junction; relative fit adjusts
  its internal hatch spacing. Each uses a separate local placement.
- Saudi zebra stripe width and gap stay at 0.5 m; the number of stripes fills
  the road. Its along-road depth adapts within our 2-6 m visual-fit range.
  The 6 m upper cap is an application choice, not an SHC requirement.
- Press Update 2D texture after changing controls, then Update view in 3D.
  Settings/history retain fit choices and speed/profile changes.

FIXED ERROR
The supplied traceback was a ZeroDivisionError: a zero-width detected approach
made relative stripe width + gap equal zero. Degenerate approaches are skipped,
periods and raster dimensions are guarded, and effective per-placement values
are saved with each placement so its image and physical footprint agree.

Source references are stored in generated preset placements as rule_ref.

SCOPE AND ASSUMPTIONS
This applies the verified dimensions and colour rules above, not every rule in
the 575-page manual. Existing lane counts, inferred junction priorities,
highway continuity, edge-line junction clipping, roundabout lane trajectories,
and automatic decal location choices retain the previous topology logic.
No alpha map can supply signs, traffic priority, passing sight distance,
pedestrian demand or permitted turning movements. The existing placement
options remain visual assumptions that the user controls. A double centre
line group is a manual choice, not an inferred engineering no-passing zone.
Cyclist crossing and arrow-shape dimensions retained from the previous guide
are not asserted to be Saudi-standard drawings. Custom guide dimensions and
learned sizes remain available. Design speed tables overlap at 100 km/h and
the no-passing width table omits exactly 80 km/h; the implementation chooses
the higher-speed category at these boundaries. Lower-speed width ranges
use 0.15 m where 0.10-0.15 m is allowed.
