# Looks that come with the program

LUTs and looks put in this folder show in the 3D tab's Look panel for every
workspace, under "Came with the program":

- `.cube` files (3D or 1D, Adobe/Resolve format) and Hald CLUT pictures
  (`.png`) appear in the LUT list;
- `.json` look files (from the Look panel's Download) appear in the Look list.

Your own looks and the LUTs you import are kept in the workspace instead
(`workspace/looks`), so updates of the program never touch them.

Only put files here whose licence lets them be shared with the program.
